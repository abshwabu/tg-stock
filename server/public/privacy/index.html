የኔ ሱቅ (Inventory) — የመጨረሻ የተሻሻለው፦ ህዳር 2026 / November 2026

ዋነኛ መርህ፦ የኔ ሱቅ (Inventory) የተሰራው ከመስመር ውጭ (Offline-First) እንዲሆን ነው። በነባሪነት ሁሉም የሱቅዎ መረጃዎች፣ የዕቃዎች ዝርዝር፣ የደንበኞች ስም፣ ሽያጮች እና የብድር (ዱቤ) መረጃዎች በስልክዎ ላይ ብቻ ይቀመጣሉ። ወደ ማናቸውም ሰርቨር አይላኩም።

1. የምንሰበስባቸው መረጃዎች

ከመስመር ውጭ (Offline) ሲጠቀሙ፦

  • ምንም ዓይነት መለያ (Account) መክፈት አይጠበቅብዎትም።
  • የዕቃዎች፣ የዋጋ፣ የሽያጭ እና የደንበኛ መረጃዎች በስልክዎ የውስጥ ማከማቻ (SQLite) ላይ ብቻ ይቀመጣሉ።
  • ምንም ዓይነት የሶስተኛ ወገን መከታተያ (Analytics/Tracking SDKs) ወይም ማስታወቂያ በመተግበሪያው ውስጥ የለም።

የመስመር ላይ ማመሳሰልን (Online Sync) ሲያበሩ፦

  • የቴሌግራም መለያ፦ ሱቅዎን ከቴሌግራም ቦት ጋር ለማገናኘት የቴሌግራም መለያ ቁጥርዎ (Telegram User ID) እና ስምዎ ይመዘገባል።
  • የመሣሪያ መለያ፦ ስልክዎን ከሱቅዎ ጋር ለማገናኘት የሚረዳ የመሣሪያ ስም እና ሚስጥራዊ ቁልፍ (Device Token)።
  • የሱቅ መረጃዎች፦ የዕቃዎች፣ የሽያጭ፣ የክፍያ እና የዱቤ መዝገቦች። ደንበኞችን ካስገቡ ስማቸው፣ ስልክ ቁጥራቸው እና ማስታወሻዎችም ሊመሳሰሉ ይችላሉ።

2. መረጃዎችን እንዴት እንደምንጠቀም እና እንደምንጠብቅ

  • የመተግበሪያው የኔትወርክ ግንኙነት HTTPS ይጠቀማል፤ የሚደገፈው የTLS ስሪት በሰርቨሩ እና በAndroid መሣሪያ ይወሰናል።
  • የእርስዎን መረጃ ለሶስተኛ ወገን አንሸጥም፣ አናከራይም ወይም ለማስታወቂያ አንጠቀምም።
  • መረጃዎ የሚያገለግለው እርስዎ ለሚፈልጉት የሱቅ ስራ እና የሂሳብ ማመሳሰል ብቻ ነው።

3. መረጃን የመሰረዝ መብት (Right to Deletion)

የመስመር ላይ መረጃዎን በማንኛውም ጊዜ ሙሉ በሙሉ መሰረዝ ይችላሉ፦

  • ከመተግበሪያው፦ በመተግበሪያው ውስጥ ወደ "ቅንብሮች > መስመር ላይ እና ቡድን" በመግባት "የመስመር ላይ መረጃን አጥፋ" (Delete Online Data) የሚለውን በመጫን በሰርቨሩ ላይ ያሉ የሱቅዎን መረጃዎች በሙሉ ወዲያውኑ ማጥፋት ይችላሉ።
  • ከቴሌግራም ቦት፦ በቦቱ ላይ /delete_shop ትዕዛዝ በመላክ የሱቁን ክላውድ መረጃ በቅጽበት ማጥፋት ይቻላል።

4. የመረጃ ቅጂ (Backups)

መተግበሪያው የራስዎን የውሂብ ቅጂ በፋይል መልክ (.sqlite) እንዲወስዱ እና ወደ ቴሌግራም "Saved Messages" ወይም የፈለጉት የክላውድ መተግበሪያ ላይ እንዲልኩ ያስችልዎታል። ይህ ፋይል በእርስዎ ሙሉ ቁጥጥር ስር ያለ ነው።

5. እኛን ለማግኘት

ስለ ግላዊነት ፖሊሲው ማንኛውም ጥያቄ ካለዎት በሚከተለው አድራሻ ሊያገኙን ይችላሉ፦

Core Principle: Inventory (የኔ ሱቅ) is engineered as an offline-first application. By default, 100% of your store data—products, sales, customer ledgers, and credit balances—resides strictly inside your phone's local storage.

1. Information We Collect

When used offline (Default):

  • No user account or personal signup is required.
  • Inventory movements, transactions, prices, and customer records remain on your device in a local SQLite database. The current app does not encrypt the database itself.
  • Zero advertising SDKs, third-party analytics trackers, or profiling tools are bundled.

When Online Sync is explicitly enabled:

  • Telegram User Identity: Your Telegram numeric user ID and first name to associate shop ownership and staff roles.
  • Device Pairing: A device name and an authorization token (UUIDv7) to secure device communication.
  • Store Ledgers: Inventory catalog, sales, payments, and customer records. If you add customer names, phone numbers, or notes, those fields can be sent to the server when sync is enabled.

2. Data Security & Usage

  • Network requests use HTTPS; the supported TLS version depends on the production server and Android platform.
  • We never sell, rent, monetize, or share merchant data with advertisers or brokers.
  • Data is processed exclusively to provide inventory synchronization and store alerts requested by the shop owner.

3. Data Retention & Deletion

You maintain complete ownership of your business data. You can erase online records at any time:

  • In the App: Navigate to Settings > Online & Team > "Delete Online Data" to permanently purge all cloud records from the server.
  • Via Telegram: Issue the /delete_shop command to instantly wipe all shop records from the server database.
  • Local Data: Clearing the app storage or uninstalling the app permanently purges all on-device records.

4. Backups

The application provides built-in tools to create standalone SQLite backup files that can be exported directly to your Telegram Saved Messages or any personal cloud storage. These files remain under your sole custody.
